# PromptRange ranges, testing and model settings

<a id="help-prompt-dashboard"></a>

## PromptRange dashboard

Home shows update time, overview cards, usage trends, model distribution, top Prompts, range health and risk indicators.
**Refresh** reloads statistics; **Workbench** opens editing/testing. Popular-item links select the relevant range or lane.
The dashboard is not an editor. Average score, usage count and health have different definitions;
missing data is neither a perfect score nor proof of no provider charges.

<a id="help-prompt-workbench"></a>

## Prompt workbench

Select a range, lane and model; edit the prompt and request parameters, run a test, then inspect results, scores and versions.
Model capabilities determine text/image/audio input and output regions; text-generation settings do not apply to every model.
Optimization, mind maps, agent creation and plugins import/export are separate actions, not saving the current test result.
The **Select range** help explains range/lane management only; model configuration has its own section below.

<a id="help-prompt-range"></a>

## Selecting ranges and lanes

This help belongs to the top-left selection area. Select or create a range first, then select its lane.
Lane selection is unavailable without a range. Dropdown actions rename/delete objects; lanes also offer comparison
and setting/resetting names. Check unsaved edits before switching and compare versions before overwriting or deleting.
Nearby plugins import/export handles plugin data; it is not a backup of all system configuration.

<a id="help-prompt-models"></a>

## PromptRange model settings

Configure the models used for prompt testing and evaluation, then verify the
selected model in the prompt page. Distinguish model configuration from the
prompt text and from knowledge-base embeddings. Model access and credentials
still depend on the configured provider.
