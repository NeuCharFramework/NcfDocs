# SenMapic crawl tasks and results

<a id="help-crawler"></a>

## SenMapic crawl tasks

Create a task with its start URL and bounded concurrency, duration, depth, and
page count. Start with small limits and inspect task details before scaling up.
Only crawl sources you are authorized to access; respect site rules and content
rights. Starting a task and viewing its status are different operations.

<a id="help-crawler-detail"></a>

## Crawl task details

Inspect the selected task's results and source information such as domain and URL here, rather than create a new task.
Check sources against task configuration. Return to task management to change the start URL or run limits.
Viewing details does not crawl again; existing results do not prove that every page parsed successfully.
