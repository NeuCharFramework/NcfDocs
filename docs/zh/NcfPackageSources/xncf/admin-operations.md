# 后台页面与上下文帮助

本文说明现有后台控件的用途，不代表新增权限，也不保证所有服务提供商具备相同能力。
请先安装并启用所需模块；删除、执行、部署等操作先在测试环境验证。
点击帮助不会执行相邻按钮、提交表单，也不会把页面查询参数发送到文档站。

问号入口默认在弹窗中显示文档；如果浏览器阻止嵌入，请选择“在新窗口打开”。
中文界面使用中文文档，其他语言界面使用英文文档。本页显式锚点在中英文中保持一致，
属于 UI 链接约定，修改标题时请勿删除这些锚点。

<a id="help-admin-users"></a>

## 管理员

在“管理员管理”中创建或编辑管理员，然后授予对应角色。
重置凭据或调整角色前核对目标用户名。管理员账号不同于 Accounts 模块的业务用户，
也不同于微信关注用户。不要把密码粘贴到文档、聊天或日志中。

<a id="help-admin-roles"></a>

## 角色与权限

先创建角色，再设置权限树，并将角色授予目标管理员；分别保存后，用受影响的账号验证。
能看到菜单不等于拥有 API 或 Function 权限。遇到拒绝访问时，先检查角色归属、
权限码、模块是否可用，以及独立的 NeuCharPivot 策略，不要直接扩大授权范围。

<a id="help-admin-menus"></a>

## 菜单

菜单管理用于维护导航、父子层级及目标地址。保存后验证实际跳转。
隐藏菜单不是权限隔离，目标页面仍须服务端鉴权。
模块提供的导航应与模块开启状态保持一致。

<a id="help-system-config"></a>

## 系统配置

保存宿主设置前先核对现有值。登录有效期会影响会话行为；页脚内容是展示配置，
不是存放可执行代码或凭据的位置。这里的设置不能替代部署环境中经批准的
服务商凭据及宿主配置源。

<a id="help-tenants"></a>

## 租户

仅在宿主已启用多租户时使用租户管理。操作前核对目标租户，创建后检查初始化结果。
有租户记录不等于模块、权限都已准备好。
参见[多租户配置](/zh/start/config/mutiple-tenant.html)。

<a id="help-accounts"></a>

## Accounts 业务账号

Accounts 页面管理应用用户，不是后台管理员或租户管理员。
通过页面提供的查询、编辑入口操作，保存前核对目标用户身份。

<a id="help-logs"></a>

## 日志

按日期选择相关日志文件，将时间与失败操作对应起来。
浏览器 Console 与服务器日志是不同来源。分享诊断片段前，
请移除令牌、凭据、个人数据和私有文档内容。

<a id="help-host-monitor"></a>

## Host 资源监控

首页面板整合 Host/Web 进程的实时指标和历史趋势。选择时间范围、缩放查看区间，
分析后可回到实时跟随。CPU、内存使用百分比轴，网络吞吐量使用 Mbps 轴；
曲线相似不代表指标单位相同。
历史记录保存在有容量及时间边界的缓存中，空白区间可能是没有保留采样，不表示利用率为零。

<a id="help-module-functions"></a>

## 模块生命周期与 Function

进入模块管理页后，先检查已安装版本、是否需要更新以及开启状态。
安装不等于开启。执行前阅读 Function 的描述和参数，尤其是数据库、文件、
部署及清理操作。通用 Function 帮助只解释操作流程，不能代替各模块的具体功能说明。
参见[模块管理](/zh/start/start-develop/admin-module-manage.html)。

<a id="help-admin-chat"></a>

## AdminChat

新建或选择会话，选择可用模型，并在发送前确认当前模式。
会话历史、Workspace 关联和当前模型是不同的配置；切换会话不代表授权修改文件。
检查生成内容和工具请求，不要把流畅的回答当作任务已经完成的证据。

<a id="help-chat-harness"></a>

## 普通对话与 Harness

**普通对话（Simple）**用于常规交流；**Harness**用于更长的工具驱动任务，
并提供进度与审批交互。批准前阅读拟执行的动作；中断任务并不会回滚已经发生的副作用。
通过轨迹、历史等入口核对实际执行情况。
Workspace 写入权限与执行权限始终需要分别明确授权。

<a id="help-chat-attachments"></a>

## 附件、视觉与大文件

仅向可以访问 Workspace 的会话上传、粘贴或拖入受支持文件。
上传提示显示当前生效限制，不要假设所有文件都能完整放入模型上下文；
大文件可能需要分块读取 Workspace，或另行授权处理。

上传文件**不代表**授权 AI 写入、执行 Python 或其他命令。
图像视觉需要主动勾选并选择兼容模型；扫描 PDF 可能需要 OCR。
上传成功不代表文本解析成功。移除尚未发送的附件可能删除其 Workspace 资源，
不要用此操作代替隐藏已经提交的文件。

<a id="help-workspace-permissions"></a>

## Workspace 权限

Workspace 保存持久文件，运行时只是执行环境。
读取、允许 AI 写入、CLI/Python 执行是不同权限级别，创建会话时只授予所需级别。
默认原生运行时不表示已经开放代码执行；有 Docker 也不会自动获得执行权限。

远程网关同时检查 DesktopBridge 设备会话、管理员 JWT 和所有权。
远程访问使用 HTTPS。撤销设备会话不会删除 Workspace 文件。
参见 [Workspace 与 AdminChat](./workspace-adminchat.md)。

<a id="help-neubell"></a>

## NeuBell 与出站 WebHook

页脚订阅控制显示哪些 Provider 的通知。WebHook 页面则单独设置条目新增/移除时的
出站通知，包括 Provider 筛选、HTTP 方法、请求体模板与可选签名密钥。
核对接收地址，用可控的接收端执行“测试”，再开启生产通知。
一次测试成功不保证未来投递成功。不要在 URL 或公开示例中放置密钥。

<a id="help-pivot-access"></a>

## NeuCharPivot 访问策略

策略可以开放、限制、禁止或继承模块 Function 的访问权限。
数据库策略覆盖相应代码属性，批量修改前核对选中的 Function。
恢复继承与清除存储策略是不同操作。
模块删除后孤儿策略可能保留，并在重装后再次生效，不能假设其自动消失。

<a id="help-pivot-boards"></a>

## NeuCharPivot 面板

面板用于组织 Function 区块。添加前核对模块与 Function 身份。
“模块缺失”占位不是执行成功，应恢复模块或删除过时区块。
把区块放入面板不会绕过 Function 的访问策略。

<a id="help-pivot-aggregate"></a>

## NeuCharPivot 聚合

聚合将选定 Function 的输入与执行视图组织在一起。
逐一核对参数、模块可用性和访问结果。
不要假设组合操作是数据库事务，也不要假设失败会自动撤销先前效果；
高影响操作先单独验证。

<a id="help-mcp-connections"></a>

## MCP 客户端连接与本站发布服务

“本站发布的 MCP”面板列出宿主暴露的端点，不是客户端连接编辑器。
连接远程 MCP 服务时，在客户端区域选择“新增 Endpoint”，选择传输方式并配置所需授权。
连接或调用工具前核对目标端点。列表中存在地址不代表匿名或公网可访问。
参见 [MCP 基础使用](/zh/MCP/basic-usage.html)。

<a id="help-ai-models"></a>

## AI 模型配置

选择服务提供商，填写端点、模型/部署名称及必需凭据。
聊天模型与 Embedding 模型用途不同，应为调用方选择兼容配置。
排查提示词之前，先确认连接和提供商的配置要求。凭据必须保密。

<a id="help-ai-vectors"></a>

## 向量存储配置

选择后端并配置连接，再由知识库引用。下拉框中存在某个选项，
不代表外部数据库已经安装或连通。Memory 不适合作为持久生产存储。
更换 Embedding 模型或向量配置可能需要重建索引；变更前备份需要保留的数据。

<a id="help-ai-tokens"></a>

## Token 监控

通过 Token 监控查看已记录的模型用量及对应筛选结果。
Token 数不是字符数、文件大小或本地文本抽取上限。
缺少监控记录不能证明没有发生服务商调用，涉及费用时应与服务商账单核对。

<a id="help-ai-dashboard"></a>

## AI 仪表盘

仪表盘用于概览已配置 AI 资源及已记录用量；详细情况转到模型、向量或 Token 页面。
解释汇总数据前先确认时间范围及实际可用数据。

<a id="help-fine-tuning-workers"></a>

## 微调 Worker

先选择已启用且已配置密钥的 Worker，再上传数据集或创建任务。
登记 Worker 端点不会自动安装运行时、下载模型或授予网络访问。
后端必须与宿主匹配，并使用经批准的本地模型。
部署、数据格式、参数范围、监控和产物注册见[本地微调指南](./aikernel-local-fine-tuning.md)。

<a id="help-knowledge-base"></a>

## 知识库与向量化

1. 新建知识库，选择 Embedding 模型和向量存储。
2. 在配置中关联需要检索的资料。
3. 执行“向量化”，检查结果并处理失败，再进入测试。
4. 用真实问题做召回测试，同时检查原始来源。

修改资料或 Embedding 配置，不代表存储的向量已经更新，应按需重新构建。
将内容发送给外部 Embedding 服务前，先确认资料访问权限和保留要求。

<a id="help-knowledge-recall"></a>

## 召回测试与 Top K

选择已向量化的知识库，输入真实问题，检查返回片段、来源名称、链接及排序。
从较小的 **Top K** 开始（页面建议 5），再根据相关性和覆盖程度调整。

相似度分数是排序参考，**不是召回率百分比，也不是答案正确概率**。
不同模型、后端的分数尺度可能不同。启用重排时，区分重排分数/顺序与原始向量排序。
判断前查看完整段落；一次问题测试成功不能证明整个知识库都已达到质量要求。

<a id="help-prompt-range"></a>

## PromptRange 提示词靶场

编辑或测试前先选择靶场与靶道。比较分数时保持模型配置、测试输入及评价标准可比；
单个样例高分不保证其他输入同样有效。覆盖或删除前先比较版本。
导入/导出 plugins 与创建智能体是独立动作，确认前核对目标。

<a id="help-prompt-models"></a>

## PromptRange 模型设置

配置提示词测试和评价使用的模型，再到 Prompt 页面核对实际选择。
区分模型配置、提示词文本与知识库 Embedding。
模型访问能力及凭据仍取决于对应服务商配置。

<a id="help-prompt-skills"></a>

## Skill

导入或启用前阅读 Skill 内容及其预期工具。
Skill 指令不是权限授权，不要把密钥写入 Skill 文件，
也不要未经审核就认为外部导入指令可以安全执行。

<a id="help-file-manager"></a>

## FileManager 文件资源

通过目录、分类、标签、搜索及页面提供的文件操作组织资源。
重命名、移动、删除前核对选中项。
FileManager 资源与会话 Workspace 文件生命周期不同，一处出现的文件不会自动在另一处可用。

<a id="help-file-uploads"></a>

## 上传设置

上传前检查允许扩展名、过滤扩展名及单文件大小限制。
宿主或反向代理还可能施加额外请求限制。
扩展名被接受不代表内容安全或可解析，不要为绕过无关网络错误而放宽上传策略。

<a id="help-agents-hub"></a>

## AIAgentsHub

当前模块首页显示注册信息与自动生成模块提示，并不是 AgentsManager 编排控制台。
Agent/Group 执行与人工介入请使用 [AgentsManager](./agents-manager-human-in-the-loop.md)。

<a id="help-workflow-tasks"></a>

## Workflow 任务

启动或修改前查看任务定义、状态及执行信息。
等待人工输入时应提交要求的响应，不是反复启动。
节点行为、触发器、表达式及 Agent 集成见 [Workflow 指南](./neuchar-workflow.md)。

<a id="help-workflow-replay"></a>

## Workflow 回放

回放用于检查一次运行的节点顺序、输入输出及失败情况；记录中可能含敏感数据。
查看记录不是撤销操作，重新运行可能重复外部副作用。
确认操作前先核对相应按钮的含义。

<a id="help-workflow-analytics"></a>

## Workflow 统计

比较执行数量或结果前确认范围和时间区间。
通过任务/回放页面调查单次失败，汇总指标不能替代原始运行记录。

<a id="help-desktop-pairing"></a>

## DesktopBridge 设备配对

批准前核对桌面生成的配对码、客户端名称和来源地址，拒绝非预期请求。
检查活动会话，撤销不再需要连接的设备。
设备配对与管理员身份、Workspace 所有权检查是不同环节。

<a id="help-dynamic-data"></a>

## DynamicData

按数据表定义、布局、页面配置/渲染的顺序构建动态界面。
模块首页可能仅展示生成模块信息，实际编辑应进入具体配置页。
面向其他用户开放前先用可丢弃的测试数据验证。

<a id="help-dynamic-tables"></a>

## 动态数据表

定义数据表和字段，包括标识、类型、必填/唯一约束及展示元数据。
更改结构前检查现有数据，界面验证不能代替后端验证。

<a id="help-dynamic-layouts"></a>

## 动态布局

先选择数据源并绑定列/字段，再配置按钮、事件、弹窗和导航。
在预览中逐项验证绑定；按钮名称不能决定效果，应检查实际配置的动作。

<a id="help-dynamic-pages"></a>

## 动态页面与渲染

将目标布局关联到页面，并用代表性数据检查渲染结果。
发布前核对查询、编辑、验证和导航行为，预览成功不代表获得了数据访问权限。

<a id="help-crawler"></a>

## SenMapic 采集任务

创建任务时配置起始 URL，并限制并发、时长、深度及页面数量。
先以小范围运行，查看任务详情，再考虑扩大规模。
只采集有权访问的来源，遵守站点规则和内容权利。
启动任务与查看状态是不同操作。

<a id="help-weixin-accounts"></a>

## 微信公众号

按部署要求配置对应公众号身份、AppId、AppSecret、Token 和加密设置，并保护凭据。
修改配置或提示词关联前核对当前公众号。
此处不同于个人微信 Bot 的连接入口。

<a id="help-weixin-users"></a>

## 微信关注用户

查看或管理关注用户前先确认公众号。
标识符和资料属于个人数据，应遵守平台授权与消息限制。
本地存在用户记录不代表同意任意出站消息。

<a id="help-weixin-claw"></a>

## 个人微信 Bot

通过页面扫码/登录流程连接目标账号，并检查运行状态，断开不再使用的账号。
Bot 已连通不代表自动获得 AdminChat、Workflow 或 Workspace 操作授权。

<a id="help-weixin-integration"></a>

## 个人微信与后台集成

显式配置管理员绑定及所需功能权限，并保护绑定码。
Chat、Workflow、NeuBell、Harness 是独立能力，只开启需要的部分。
批准任务前核对绑定身份，停用账号或设备时应处理解绑。

<a id="help-database-samples"></a>

## 数据库示例页

这些页面用于模块开发演示，不是通用生产数据库管理台。
执行示例写操作前核对模块和当前数据库类型。
部署配置及迁移参见[数据库指南](/zh/start/database/setting.html)。
