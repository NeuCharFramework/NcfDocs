# 连接器：受控接入外部工具

<a id="help-connectors"></a>

## 连接器配置页

`Senparc.Xncf.Connectors` 把外部工具账号保存为可选择的“连接器”。连接器类型
由已安装的模块提供；本页负责保存账号、保护密钥、启用动作，以及决定它是否可被
Chat、Workflow 或 Agent 模板使用。

连接器配置页仅允许 `AdminSuperAdmin` 使用。普通模块用户不应配置共享凭据。

## 第一次配置

1. 安装并启用提供连接器类型的模块。
2. 打开 **连接器**，选择 **配置这个连接器**。
3. 填写容易识别的名称，例如 `总部企业微信`。
4. 填写账号字段和密钥。密钥保存在服务端，编辑时不会以明文返回。
5. 只选择这个账号真正允许执行的动作。
6. 启用连接器并保存。
7. 点击 **测试**，确认外部服务接受凭据后，再在 Chat、Workflow 或 Agent
   模板中选择它。

已经保存的密钥如果留空，表示继续使用旧密钥；要替换密钥时输入新值。删除连接器
后，已有 Agent 引用也会停止工作。

### 第一次测试的安全顺序

如果还在整理凭据，可以先保存为禁用状态。保存后先测试一个影响较小的动作，
确认无误再让 Chat、Workflow 或 Agent 使用。测试成功只说明服务器当时接受了这个动作；
不代表所有动作都安全、不代表所有用户都有权限，也不代表外部服务一直可达。

编辑窗显示掩码密钥时，不要把掩码文字复制回输入框。留空表示继续保留服务端旧密钥；
密钥轮换后请输入新值。不要把外部服务密钥放进连接器名称、备注、Workflow 输入、
Agent 提示词、导出配置或截图。

## 权限如何生效

连接器页面只控制某个账号允许执行哪些动作，并不自动授予所有用户调用权限。
调用方仍需经过自己的授权和策略检查：

- Chat 可以在单次对话中进一步收窄动作范围；
- Workflow 在 Function 节点中选择连接器和动作；
- Agent 模板决定某个智能体可以使用哪些连接器。

请把连接器密钥和动作权限按生产凭据管理：遵循最小权限原则，通过外部服务轮换
密钥；修改或删除连接器后，检查 Agent 和 Workflow 的引用。

## 排障顺序

| 现象                   | 优先检查                                          |
| ---------------------- | ------------------------------------------------- |
| 没有连接器类型         | 是否安装并启用了注册该类型的模块。                |
| 保存被拒绝             | 名称、必填字段和动作值是否完整。                  |
| 测试失败               | 外部账号、网络、密钥是否已轮换，以及服务端日志。  |
| Chat 或 Agent 无法选择 | 连接器是否启用，以及调用方策略是否允许该动作。    |
| 删除后仍有引用         | 在 Agent 模板或 Workflow 节点中删除或替换旧引用。 |

连接器模块负责保存配置和派发动作；外部服务的账号权限、网络可达性、限流和
提供方行为仍由外部系统决定。
