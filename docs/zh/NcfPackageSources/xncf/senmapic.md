# SenMapic 采集任务与结果

<a id="help-crawler"></a>

## SenMapic 采集任务

创建任务时配置起始 URL，并限制并发、时长、深度及页面数量。
先以小范围运行，查看任务详情，再考虑扩大规模。
只采集有权访问的来源，遵守站点规则和内容权利。
启动任务与查看状态是不同操作。

<a id="help-crawler-detail"></a>

## 采集任务详情

详情页查看选定任务的结果及 domain、URL 等来源信息，不是新增任务表单。
用来源地址和任务配置核对采集范围；需要改变起始地址或运行限制时返回任务管理。
查看详情不会重新采集，结果存在也不代表所有页面都成功解析。
