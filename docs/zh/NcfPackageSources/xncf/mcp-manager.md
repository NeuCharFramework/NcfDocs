# MCP Manager：服务查看与客户端连接

<a id="help-mcp-manager"></a>

## MCP Manager 管理页

本页有两类不同对象：“本站发布的 MCP”只读展示宿主实际映射的服务、模块、路由和访问端点，
可筛选、刷新和复制地址；发布开关及权限由所属模块管理。
“客户端连接配置”管理 NCF 连接外部 MCP 的 Endpoint，可新增、编辑、启用、测试或删除。
不要在客户端列表中寻找本站服务的发布开关，也不要把复制地址当作已经完成鉴权。
MCP 协议及 Server 开发方式另见 [MCP 模块](../../MCP/home/index.md)。

<a id="help-mcp-connections"></a>

## MCP 客户端连接配置

此问号对应连接外部服务的编辑器。选择“新增 Endpoint”，填写唯一名称、端点地址、
端点类型及可选协议版本、描述和授权配置；“保存前测试”检查当前表单，“保存”才保存连接。
列表的启用开关与“测试”不同；最近测试状态、工具数量和详情用于诊断连接。
连接或调用工具前核对目标端点。列表中存在地址不代表匿名或公网可访问。
参见 [MCP 基础使用](../../MCP/basic-usage.html)。
