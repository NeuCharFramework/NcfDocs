# 后台日志查询与排障

<a id="help-logs"></a>

## 日志

按日期选择相关日志文件，将时间与失败操作对应起来。
浏览器 Console 与服务器日志是不同来源。分享诊断片段前，
请移除令牌、凭据、个人数据和私有文档内容。

<a id="help-log-details"></a>

## 指定日期的日志详情

此页查看选定日期的 SenparcTrace 文件，可切换完整结果/异常信息，并按关键字、开始与结束时间、
线程、类型和异常状态筛选。行号、时间、标题及内容用于定位一条记录，不是重新执行请求的入口。
“没有结果”可能是筛选范围内没有匹配项；排查前先核对日期和筛选条件。
