# PromptRange 靶场、测试与模型配置

<a id="help-prompt-dashboard"></a>

## PromptRange 统计首页

首页展示更新时间、概览卡片、调用趋势、模型分布、热门 Prompt、靶场健康度及风险提示。
“刷新”重新获取统计，“工作台”进入 Prompt 编辑/测试页，热门项链接定位相应靶场或靶道。
统计页不是编辑器；平均分、调用次数和健康度有不同口径，不要把无数据解释为满分或没有模型费用。

<a id="help-prompt-workbench"></a>

## Prompt 工作台

先选择靶场、靶道和模型，再编辑提示词与请求参数，执行测试并查看结果、评分和版本。
模型能力决定文本、图像、音频等输入输出区域；不要把文本生成的参数直接用于所有模型。
优化、导图、创建智能体、plugins 导入/导出是独立动作，不等于保存当前测试结果。
工作台中的“选择靶场”问号只解释靶场/靶道管理；模型配置另见“PromptRange 模型设置”。

<a id="help-prompt-range"></a>

## 选择靶场与靶道

此问号对应工作台左上方的选择区。先选择或新增靶场，再选择其靶道；
没有靶场时靶道选择不可用。下拉项可重命名或删除，靶道还可比较、设置/重置名称。
切换对象前核对当前编辑内容，覆盖或删除前先比较版本。
旁边的导入/导出 plugins 针对插件数据，不能当作无差别备份全部系统配置的功能。

<a id="help-prompt-models"></a>

## PromptRange 模型设置

配置提示词测试和评价使用的模型，再到 Prompt 页面核对实际选择。
区分模型配置、提示词文本与知识库 Embedding。
模型访问能力及凭据仍取决于对应服务商配置。

## AdminChat 系统提示词靶场

AdminChat 内置默认 SystemMessage 存储在 `AdminChat.SystemMessage`
PromptRange 靶场中。首次使用时会自动初始化该靶场，后续选择当前评分最高
的已发布版本。可以从 AdminChat 设置入口打开靶场编辑器，在其中发布并评分
版本。该默认提示词与用户个人 SystemMessage、租户全局 SystemMessage 相互独立。
