# AgentsManager 智能体管理

<a id="help-agents-manager"></a>

## Agents 管理首页

### 日常操作顺序

1. 搜索或新增智能体，核对其资料与设置，避免编辑同名的其他对象。
2. 在对应智能体下检查组和任务，再选择启动、停止或重新运行；批量操作前复核选中项。
3. 运行后查看任务状态；需要人工响应时使用 HIL 入口，不要用重复启动代替响应。
4. 需要对外提供能力时单独配置 A2A 发布与访问边界，而不是仅创建一条智能体记录。

<a id="help-agents-ai-shortcut"></a>

### 通过 AdminChat 启动现有小组

AgentsManager 页面底部的 **AI** 按钮会逐字填入 `/run-agent-group `。继续输入任务描述，也可以显式
补充小组 ID 或名称。该命令只允许搜索和启动现有小组，不会创建、修改或删除 Agent、小组或对话。

模型先按任务关键词和语义检查启用小组的名称、说明及成员；只有明确匹配时才启动，并把命令后文本作为
任务指令。出现多个候选时必须让管理员选择，而不是自行猜测。“任务已启动”只表示异步任务已创建，不代表
执行完成；后续应在 AgentsManager 的 ChatTask 与 HIL 入口查看状态。

### 视图与专题

首页可新增、搜索和编辑智能体，切换面板、3D 或统计视图，并管理远程 A2A 智能体。
选中智能体后查看资料、设置、组和任务；组的启停、批量任务操作与编辑智能体配置是不同动作。
发布 A2A 会改变对外提供能力的方式，应单独检查访问配置；查看任务并不启动新的执行。
3D 标记含义见 [3D 状态视图](./agents-manager-3d-status.md#help-agents-status)，
等待人工输入时再参阅 [HIL 与 Workflow](./agents-manager-human-in-the-loop.md)，不要把 HIL 专题当作整个首页说明。
