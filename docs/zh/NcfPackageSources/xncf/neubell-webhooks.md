## NeuBell 与出站 WebHook

本页是出站 WebHook 管理：新增、编辑或启用地址，选择条目新增/移除事件、
Provider 筛选、HTTP 方法、请求体模板与可选签名密钥。
请求日志可查看 HTTP 状态、耗时和报文；“清空”针对显示的请求记录，不是删除所有 WebHook。
页脚的 Provider 订阅决定显示哪些通知，是另一套设置。
核对接收地址，用可控的接收端执行“测试”，再开启生产通知。
一次测试成功不保证未来投递成功。不要在 URL 或公开示例中放置密钥。
