# 微信公众号配置与关注用户

<a id="help-weixin-overview"></a>

## 公众号控制中心

首页显示已录入公众号数、运行账号数、总微信用户数和今日新增用户数。
展开公众号可通过“查看用户”进入该账号的关注用户列表，通过“编辑”进入公众号管理。
这些统计不是实时微信平台账单；页面中的占位链接不能被当作已实现的分组、标签或对话功能。

<a id="help-weixin-accounts"></a>

## 微信公众号

按部署要求配置对应公众号身份、AppId、AppSecret、Token 和加密设置，并保护凭据。
修改配置或提示词关联前核对当前公众号。
编辑页中的 PromptRangeCode 关联提示词；回调地址供微信平台配置使用，不是聊天窗口。
此处不同于个人微信 Bot 的连接入口。

### 字段从哪里取得

AppId、AppSecret、Token 和 EncodingAESKey 应从微信公众号平台的官方账号设置中取得。
其中 **Token** 和 **EncodingAESKey** 必须与平台回调配置中的值一致，不是可以随意编写的密码。
把 NCF 显示的回调地址填入微信平台的服务器配置，先完成平台侧验证，再测试消息。

建议先保存一个公众号并确认运行状态，回调和凭据确认可用后，再增加第二个账号或关联
PromptRangeCode。不要把 AppSecret、EncodingAESKey 放进提示词、问题报告或截图。

<a id="help-weixin-users"></a>

## 微信关注用户

查看或管理关注用户前先确认公众号。
“追加同步新关注用户”与“同步所有关注用户”范围不同；同步后检查关注状态及本地列表。
标识符和资料属于个人数据，应遵守平台授权与消息限制。
本地存在用户记录不代表同意任意出站消息。

“追加同步新关注用户”适合小范围增量同步；“同步所有关注用户”用于有意进行较大范围刷新，
耗时可能更长，也可能影响较多本地记录。任一操作完成后，都要检查当前公众号、最近同步结果
和用户列表，再决定是否重复执行。
